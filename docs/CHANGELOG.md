# 变更记录

本文件记录用户可见的变化。实现细节、测量数据与设计取舍在 [TECHNICAL.md](TECHNICAL.md) 与 [PERFORMANCE.md](PERFORMANCE.md)。

格式参考 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)，版本号遵循 [语义化版本](https://semver.org/lang/zh-CN/)。

## [1.7.5] — 2026-11-07

### 新增

- **画布字墙**：绝区零字标底纹铺进 `body` 背景层，配暗角与上下收边，浓淡可调（`--fz3-wall-veil`）。
- **常驻电费读数**（BillDock）：侧栏页脚上方常驻余额 / 今日 / 倍率倒计时三行，20s 轮询，倒计时本地走字。

### 变更

- **可以 npm 安装**：发布为 `@sky_wing_dn/dsh-fairy-zzz`（npm 上原 `dsh-fairy-zzz` 属于上游作者），一条 `dsh plugin --profile desktop add @sky_wing_dn/dsh-fairy-zzz` 就能装。
- **外观暂时固定深色**：浅色版还没做完，本版起不再跟随宿主主题切换（浅色覆盖保留，恢复时改一处判断即可）。
- 设置页语音引擎两张卡合并成一张；未保存时行内提示当前生效的目录。
- 眼徽复位改为双击右键；开机收拢与拖动 / 复位共用同一条 1.35s 曲线。
- 完成动效改为一次性，只缩放眼球本体。

### 修复

- 修复长会话里眼徽落到窗口外、看起来「消失」的问题。
- 修复完成任务瞬间出现圆角方形光晕的问题（两个来源一并去掉）。
- 优化了设置页交互、眼徽定位与部分过渡动画的细节。

### 移除

- 仓库里 20 张整窗截图全部移除——它们带着侧栏工作区名与会话标题；只保留眼球 / 字标 / 自绘图表配图。
- 若干无调用点的函数、未被 `var()` 消费的 CSS 令牌、可自动重建的 `cache/`（约 69 MB）；`package.json` 的 `description` 压回一句话。

## [1.7.4] — 2026-11-06

- 同机 A/B 核查：打开 2.1 万字会话的样式耗时与 v1.6.2 持平，皮肤不是桌面端卡顿的根因；本版继续压低常驻合成成本（`background-attachment: fixed` 改 `scroll`、dock 相停掉被面板遮住的无限动画与两张全屏装饰层、去掉眼徽外圈 `blur(8px)`）。
