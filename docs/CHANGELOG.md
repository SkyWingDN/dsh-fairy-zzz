# 变更记录

本文件记录用户可见的变化。实现细节、测量数据与设计取舍在 [TECHNICAL.md](TECHNICAL.md) 与 [PERFORMANCE.md](PERFORMANCE.md)。

格式参考 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)，版本号遵循 [语义化版本](https://semver.org/lang/zh-CN/)。

## [1.7.5] — 2026-11-07

### 新增

- **画布字墙**：`assets/zzz-pattern.webp`（1600×1746）以 `cover` 居中铺进 `body` 背景层，上叠暗角、上下收边与左下青柠底光；浓淡由 `--fz3-wall-veil` 控制。桌面外壳原本在 `body` 之上压着整窗 frame 与会话列 / 会话根两层近黑背景，本版只让开这三层的背景色，不动布局。
- **常驻电费读数**（BillDock）：侧栏页脚上方常驻 `Fairyの电费` 面板，三行读数 + 计费时段说明；20s 轮询 `/usage`，倍率切换前 2.5s 补拉一次，倒计时本地每秒走字。

### 变更

- **设置页语音引擎两卡合一**：状态行、路径输入、启动 / 停止 / 刷新收进一张卡片；未保存时行内提示「未保存 · 当前生效：…（来源）」。
- 眼徽复位改为**双击右键**，开机收拢与拖动 / 复位共用同一条 1.35s 曲线（`--fz3-handoff` 删除）；dock 相收掉两团常驻青柠氛围光。
- 完成动效改为一次性：只缩放眼球本体（`.fz3-eye-svg`），1.1s 收回，不再每轮反复触发。

### 修复

- 长会话里眼徽「消失」：`measureRegion()` 的标题栏候选改为只接受视口内的满宽 / 侧栏右侧条，dock 落点最后再夹一次进视口；新增 `data-settled`，坐标写完之前不显形。
- 完成瞬间的圆角方形光晕：整套 feTurbulence 参考滤镜（`fz3-interference` / `fz3-noise` / `fz3-displace` / `ensureFilter`）删除——GPU 合成下 `url(#滤镜)` 会把输出铺满矩形区域；扩散环 `.fz3-eye-flash` 的 2px 边框在真实窗口会被渲染成圆角矩形，元素与关键帧一并删除。

### 移除

- 无调用点的 `tokensText()`、`feeText()`；8 个从未被 `var()` 消费的 CSS 令牌；随气泡废弃的 `docs/img/usage-bubble.jpg`；可自动重建的 `cache/`（约 69 MB）。
- `package.json` 的 `description` 从 4.5 KB 压回一句话。
